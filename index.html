Randomness check per market

Uniformity: are digits 0–9 equally frequent (chi-square, 9 df)? Dependence: does the next digit depend on the current one (chi-square on the 10×10 transition table, 81 df)? Dependence is the one an entry-digit strategy would need. Flagged only if p is below 0.05 / 26 tests (Bonferroni). Updates at each lock.

Read this

Deriv synthetic indices come from a certified random generator, so digits are expected to be independent. With over a hundred combinations tested, the top one will look good by chance alone, which is why the adjusted p-value and the live forward test (signals the tool never saw when it chose them) matter more than the headline win %. A rate only pays if it beats break-even (100 / (1 + payout)). Research tool only; not a guarantee.
